# Encapsulation

> Full Stack Web Development Bootcamp — Sprint 13, Day 4

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)

## About

Explores the encapsulation principle in Java, focusing on data hiding and controlled access through getters and setters. This assignment demonstrates how to protect object state and enforce invariants.

## Key Concepts

- Access modifiers (`private`, `public`, `protected`)
- Getter and setter methods
- Data hiding and information protection
- Immutable object design
